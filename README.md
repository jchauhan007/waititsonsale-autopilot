# @waititsonsale Cloud Autopilot V1

This package is designed to run on an always-on cloud host so your phone only needs to open the dashboard and tap START.

## Deploy with Render

1. Create a GitHub repository.
2. Upload all files in this folder.
3. In Render, create a new Web Service from that repository.
4. Render will use the included Dockerfile.
5. Open the generated HTTPS URL on your phone.
6. Tap START.

The included render.yaml is a starting configuration.

## What V1 does

START -> scheduled product selection -> Reel script/caption generation -> saved drafts -> repeats.

It is intentionally draft-first.

## Instagram publishing

The dashboard includes fields for Meta credentials, but this V1 does NOT fake-login to Instagram or bypass Meta permissions. To publish automatically, the next step is to connect an Instagram Professional account to Meta's official publishing API and implement the media-container/publish flow appropriate to your account and current API permissions.
